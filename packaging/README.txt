HN DeskPad

使用方法
1. 解压到任意不会被清理的文件夹（推荐使用 HN-DeskPad-Setup.exe 安装，会自动创建文件夹和快捷方式）。
2. 双击 DeskPad.exe 启动，之后按 Alt+Space 打开 / 关闭启动台。
3. 请不要以管理员身份运行。

说明
- 设置与缓存保存在 %LOCALAPPDATA%\DeskPad，删除该文件夹即可完全清除。
- 本程序暂未进行代码签名，首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」，点击「更多信息 → 仍要运行」即可。
- 系统要求：Windows 10 1809 及以上 / Windows 11，x64。
